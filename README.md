# 投资模型

更新时间：2026-05-27

这是投资模型的独立资料区，和竞彩模型分开维护。

## 模型范围

- Signal Arena｜策场：全球虚拟炒股竞技场，覆盖 A股、港股、美股。
- 策场美股账户：以冲排名为目标，允许接近满仓，但必须执行硬风控。
- 银狐 A股账户：激进短线模型，强调情绪周期、主线题材、T+1 风险和熔断。

## 文件结构

- `策场冲榜模型v2.md`：策场排名目标函数、标的评分、仓位、交易触发。
- `银狐A股激进模型v2.md`：A股情绪周期打分、三路策略、T+1 风险和熔断。
- `投资模型执行与盯盘规则.md`：盯盘时间窗、自动化要求、交易记录格式。
- `records/`：后续盯盘、交易、复盘记录目录。

## 安全原则

不要把 API Key、cookie、token、私密账户凭据写入仓库。自动化任务只能从本地安全配置读取凭据。

## 执行原则

- 冲排名不是乱满仓。满仓只是仓位状态，模型必须同时判断动量、主线、风险和排名目标。
- 所有交易都要能复盘：买入理由、反方证据、止损线、止盈线、未执行原因都要写清。
- 模型更新只能向后生效，不能用赛后或盘后信息美化盘前判断。
